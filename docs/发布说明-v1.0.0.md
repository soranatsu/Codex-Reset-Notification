# Codex Reset Notification v1.0.0

首次公开发布。独立中文 Windows 桌面工具，追踪 codex-reset.com 的公开重置公告，支持 SMTP 多收件人和可选 Bark。不是 OpenAI 官方软件，不能读取本人额度或保证本人到账。

## 使用

下载 `Codex-Reset-Notification-1.0.0-Windows-x64.zip`，完整解压后双击 `启动.cmd`。无需预装 Python 或管理员权限。不要删除 `_internal`。首次打开停止监测，首次成功检查建立无历史通知的基线；凭据由使用者本机输入。可先运行 `离线演示.cmd`。

默认 300 秒轮询，最少 60 秒；时区可配置。未完成批次默认每天当地 12:00、18:00 额外提醒，支持编辑或关闭。仅用户主动选择时保存系统凭据或设置开机启动。

## 验证与限制

- 45 项自动测试通过，使用虚构地址、mock 和本机模拟 SMTP／HTTP。
- 源码及冻结 EXE 的中文界面检查通过；解压到全新中文空格路径、移除安装 Python 路径后正常启动。
- x64、普通用户 `asInvoker`、无缺失打包依赖；运行数据、真实凭据与本机用户路径检查通过。
- 目标 Windows 10/11 x64，实际测试仅 Windows 11；第二台物理电脑、Windows 10、ARM64 原生环境未验证。
- EXE 未签名。真实 SMTP 收件箱、Bark 手机显示、原生系统凭据写入及实际开机启动未执行。

电脑关机、睡眠、离线或程序关闭时不能保证及时监测。“服务器已接受”不代表收件人已收到或阅读。第三方账户到账不会自动标记本人到账；不支持强制突破 iOS 静音或专注模式。

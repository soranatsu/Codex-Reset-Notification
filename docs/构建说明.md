# 构建和维护

项目采用 Python 标准库：Tk/ttk 图形界面、urllib 公开接口、SQLite 状态／队列、smtplib 邮件、ctypes Windows 凭据 API。运行时只额外使用 `tzdata==2025.2`，Windows 一般没有可供 zoneinfo 使用的 IANA 时区库。当前时区包经安装并测试成功；升级到更新版本时请重新验证需要的时区规则。

本次实际工具链：Windows 11 x64、Python 3.14.7、Tk 9.0、PyInstaller 6.22.1、hooks 2026.6。构建依赖及间接依赖固定在 `requirements-build.txt`。相同源码与工具版本可重复生成相同功能的包；PE 时间戳等会变化，不承诺字节完全相同。

在源代码目录的 PowerShell 中执行：

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt --index-url https://pypi.org/simple
.\.venv\Scripts\python.exe scripts\check.py
.\.venv\Scripts\python.exe scripts\build_release.py
```

已安装所列依赖时，可直接 `python scripts/build_release.py` 或 `powershell -ExecutionPolicy Bypass -File build.ps1 -Python python`。脚本只在当前项目内创建 build、dist 和 release，不修改其他项目、启动项或真实账户。

`check.py` 运行完整 unittest 集合，默认包含 Windows GUI 测试和仅绑定 127.0.0.1 的模拟 SMTP／HTTP 服务器。无需外网；不向真实邮箱或 Bark 发消息，不读写真实系统凭据，不设置真实启动项。随后启动隔离离线演示进行源 GUI 自检。

`build_release.py` 执行上述检查、生成 windowed / onedir EXE、包含时区资源、运行冻结包 GUI 自检，然后使用源码白名单创建一个包含 Windows 便携程序及完整源码的 ZIP。构建检查失败时停止打包。无管理员权限要求，不使用 UPX，不请求 UAC 提权。

本机 Python 3.14 的 Tcl/Tk 9 将界面脚本嵌入 DLL 的 ZIP。构建脚本会从已安装的官方运行时提取相同脚本到 `_tcl_data`、`_tk_data` 并显式打包，避免冻结程序启动时找不到 init.tcl。实际解压测试会移除 Python/Tcl/Tk 环境变量及 Python PATH，并使用中文空格路径和全新用户数据目录验证普通启动保持停止。此检查模拟独立使用环境，不能替代另一台实体电脑的测试。

依赖审计检查 EXE、DLL、PYD 的普通和延迟导入，只允许包内依赖及 Windows 系统组件；VC 运行库须在包内。EXE 须为 x64 且使用 `asInvoker` 清单，不请求管理员权限。真实独立普通用户账号未创建或测试。

输出：

- `dist/CodexResetNotification/CodexResetNotification.exe`：可直接运行的 Windows 程序。
- `release/Codex-Reset-Notification-1.0.0-Windows-x64.zip`：完整可交付包。
- `release/Codex-Reset-Notification-1.0.0-Windows-x64.zip.sha256.txt`：SHA-256。
- `build/checks/test-results.json`、`test-results.txt`、`source-ui-smoke.json`、`frozen-ui-smoke.json`、`package-audit.json`：验证证据，也会包含在 ZIP 中。

运行 `python app.py --demo` 可查看隔离离线演示。运行 `python app.py --data-dir <项目内测试目录>` 可在指定目录隔离状态；普通启动默认不监测。仅用户主动设置的启动入口才使用 `--start-monitor`。

模块：`app.py` 管理界面和启动入口；`core.py` 负责公开事件解析、去重、时间、SQLite 与轮询；`notify.py` 负责通道和发送状态；`vault.py` 只访问本软件的两个系统凭据项。可选 feed 回复元数据仅辅助关联，不依赖 classifier_version、tibo_lane 等内部字段。接口字段缺失时采取保守处理，不能据此推断完成。

公开 API 的准则依据 [developers](https://codex-reset.com/developers)；重置卡语义依据 [banked-reset](https://codex-reset.com/banked-reset)。无 API key、无注册、无收费 X API。原始 ID 去重，不以文案相似度或时间相邻推断同批。未发布公共支持网站，因此发布前应提供发布者的联系方式；用户运行时填写自己的接口联系信息，发布包不含私人联系信息。

安全发布白名单不包含 config.json、SQLite、日志、.env、密钥、运行目录或本机 Library 文件转移辅助文件。源码测试中的密钥标记和 `.invalid` 地址是合成样例；生产源码和冻结运行时不含这些测试值。打包审计会检查路径、秘密样例泄漏与 ZIP 完整性。

请勿把整个工作区递归压缩发布。使用构建脚本。公开分发前应在独立 Windows 电脑检查防病毒、证书、实际 SMTP/Bark 通知和用户授权后的系统凭据／启动流程，再添加发布者的签名。当前版本未进行真实通知或真实启动项测试。

发布前由 scripts/privacy_audit.py 检查白名单源码、二进制及其内嵌 Python 归档。检查个人用户路径、真实邮箱、令牌特征和运行数据；输出只包含问题类型和相对文件名，不输出秘密内容。项目当前未选择开源许可证，不要自动添加许可模板；第三方许可仍随包保留。
